# Agentic RAG Eval

A pipeline for evaluating agentic Retrieval-Augmented Generation (RAG) systems.

## Structure

- `pipeline/` — Core pipeline components (agent, ingestion, retrieval, reranker, tracer)
- `data/sample_docs/` — Sample documents for testing
- `main.py` — Entry point

## Setup

```bash
pip install -r requirements.txt
```
